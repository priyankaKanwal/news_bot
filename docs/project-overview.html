AI News Intelligence Bot

A RAG chatbot that ingests RSS news feeds daily, embeds them into a vector database, and answers questions with cited sources from the last 30 days of articles.

Workflow 1 — Daily ingestion

Triggered by ingestion/scheduler.py or POST /api/ingestion/run. Orchestrated by run_ingestion().

1. Expire old dataDelete articles and chunks older than 30 days.delete_expired_articles
2. Load feedsRead 10 RSS feeds from feeds.yaml (BBC, The Hindu, TOI, NDTV, Hacker News).load_feeds
3. FetchDownload and parse each feed; failures counted per feed.fetch_feed
4. NormalizeMap entries to a common shape; pick first image.normalize_entry
5. CleanStrip HTML, control chars, tracking URL params; stable UUID5 id; parse date.clean_article
6. Date filterKeep articles within 30 days (1-day future tolerance).filter_articles
7. Exact dedupeBy article id, URL and content key, also against stored ids.deduplicate_articles
8. Near-dupe removalJina embeddings; cosine ≥ 0.88 within 7 days = same story.detect_near_duplicates
9. Save to PostgresUpsert into articles table._store_articles
10. Chunk500-char chunks, 100 overlap, with metadata.build_documents
11. Embed + indexJina embeddings (1024-d) into Qdrant with stable chunk ids.vector_store.add_documents
12. ReportCounts: feeds, failures, duplicates, saved, chunks.print_report

Workflow 2 — Chat / RAG answer

Entry: POST /api/chat or /api/chat/stream (SSE). Answer logic in rag/answer_generator.py.

1. ValidateQuestion 3–500 chars; get or create conversation; save user message.chat_service
2. RouteBroad "latest / top / today / news" questions go to browse mode.is_browse_question
3a. RetrieveQdrant similarity search, top 10, score ≥ 0.60, 30-day filter.similarity_search_with_relevance_scores
3b. BrowseNewest unique articles, optional category/publisher filter (max 6).fetch_latest_articles
4. RerankCross-encoder keeps the top 3 chunks.rerank_documents
5. GenerateGemini answers strictly from context, temperature 0; refusal if no info.answer_chain / stream_answer
6. Persist & returnSave assistant message with sources; return answer + citations._save_assistant_message

Fallback: if a broad question gets a refusal, it is retried with the latest articles. Token usage is tracked by TokenUsageTracker.

Data models

SQLAlchemy models in backend/db/models.py, plus the Qdrant chunk payload.

Conversation conversations

id (UUID, pk), title (120), created_at, updated_at. One-to-many to messages, cascade delete.

ChatMessage chat_messages

id, conversation_id (FK), role (user | assistant, check constraint), content, sources (JSON), created_at. Index on (conversation_id, created_at).

Article articles

article_id (pk), title, content, url, publisher, category, published_at (indexed), guid, author, image_url, ingested_at.

Qdrant chunk news_articles

1024-d cosine vector. Metadata: article_id, title, publisher, category, article_url, author, image_url, published_at, published_ts, chunk_index.
